# 素材裁切與保真

## 判斷與拆分

文字、表格、面板、箭頭與簡單幾何優先原生重建。複雜圖示、插畫、照片、反射與紋理保留原始像素；不要以重新設計的圖示替換。圖示內有功能標籤時，將標籤移除再以文字框放回原座標；標誌文字等使用者已接受的具體例外，沿用 `content.rasterExceptions` 記錄。

每塊素材只對應一個有意義的視覺物件。不能連文字、面板與流程一起大範圍裁切，也不能把完整來源圖作底再疊文字。純裝飾背景可用不含文字／主要資訊的獨立紋理塊，依原位置配置。讀不清楚的字須記錄，不猜寫、不宣稱已原生化。

## 依規格裁切

所有相對路徑以規格檔所在目錄解析：

```json
{
  "source": "source.png", "outputDir": "assets/page_0001",
  "assets": [{
    "name": "原始機器人圖示", "filename": "robot.png",
    "crop": {"x": 640, "y": 310, "w": 400, "h": 380},
    "role": "complex-illustration", "containsText": false,
    "altText": "從原圖保留的機器人，外部標籤另建文字框"
  }]
}
```

```text
python scripts/crop_assets.py work/crops.json
```

工具校正 EXIF 方向後按整數像素無損輸出 PNG，不縮放、不補齊越界區域。`crop-report.json.elements` 可放入場景，包含原圖位置、尺寸、來源／素材 SHA-256 與 `sourceCrop`，建置時檢查來源與素材是否仍相符。素材 `path` 為絕對路徑，可改為相對於場景檔的路徑。搬移來源或素材時須同步更新記錄。

跨頁共用確實相同的圖示或獨立照片時，`sourceCrop` 仍指向最初裁切來源；不改寫為目前頁面的來源。配置位置以元素 `x/y/w/h` 調整，各頁仍須檢視素材是否適用。

`containsText` 是原圖判讀後的標記，不是工具的 OCR 結論。輸出後必須檢視每塊素材，確認沒裁入旁邊的標籤。相同內容可重跑；已有不同素材時停止，只有確認要取代才使用 `--force`。

## 去背與移除原文字

預設保留所有原始像素。背景不是近似純色時不要自動去背；保留與原圖相同位置的背景，或另做經檢視的遮罩。近色背景可在單個素材加入：

```json
"backgroundKey": {"color": "001827", "tolerance": 10, "feather": 4}
```

只移除與素材邊界相連的近色區域，保留不相連的內部同色細節。容差採 RGB 最大通道差 0–255，容差與羽化總和不得超過 255。由小容差開始，檢視白色高光、透明邊緣與光暈，不交付未檢視的自動去背結果。

標籤位於純色區域時，可用相對於裁切左上角的 `eraseRegions` 移除，再以原生文字重建：

```json
"eraseRegions": [{
  "x": 20, "y": 300, "w": 230, "h": 45,
  "fill": "001827", "reason": "移除功能標籤，另以同位置原生文字框重建"
}]
```

`fill` 可為六位色碼或 `transparent`。複雜背景不得用純色蓋出明顯補丁；改為縮小裁切、分塊或使用經檢視的遮罩。工具只執行指定區域並記錄操作，不會自動補回文字。

## 交付說明

分別說明原生文字／幾何，以及可移動、縮放、裁切、替換的原圖素材。保留原始圖樣不表示內部筆畫已向量化；原生簡化時也須說明圖樣已調整。逐頁對照原圖與文字，不能以圖片數少或原生物件多當作品質分數。
